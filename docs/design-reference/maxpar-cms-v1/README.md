# Maxpar CMS v1 Visual Reference

Status: approved visual reference.

This folder is a documentation artifact for a possible future closed CMS. It is not production code and is not connected to the public portfolio.

## Purpose

- Visual direction for the closed CMS.
- UX hierarchy for a desktop project editor.
- Three-panel desktop composition: site tree, editor, live preview.
- Density, spacing, and state reference for future implementation.

## Files

- `index.html` - standalone static reference page.
- `style.css` - local CSS used only by the reference page.
- `maxpar-cms-main-1536x1024.png` - primary reference screenshot.
- `maxpar-cms-secondary-1536x1024.png` - secondary reference screenshot.

## Constraints

- The reference does not define backend, authentication, API, database schema, or deployment.
- The public portfolio must not import this visual style automatically.
- Future CMS implementation may refine details while preserving the approved UX direction.
